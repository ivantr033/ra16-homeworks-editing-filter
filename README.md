# Домашнее задание к блоку «Redux» — Задачи «Редактирование» и «Фильтрация»

CRUD-приложение для управления списком услуг с поддержкой добавления, редактирования, удаления и мгновенного поиска, разработанное на React 19, TypeScript 5 и классическом Redux. Проект объединяет функциональность первых двух задач блока в едином решении.

## ⚙️ Реализованные требования и технические характеристики

Проект полностью выполняет условия технических заданий с применением следующих подходов:

1. **Централизованное управление состоянием (Redux Store):** Состояние разделено на три независимых редюсера (`servicesReducer`, `formReducer`, `filterReducer`), объединенных через `combineReducers`.
2. **CRUD-операции и режимы формы:** Реализованы режимы добавления (`editingId: null`) и редактирования (`editingId: string`) с визуальной индикацией текущего режима, названием редактируемой услуги и кнопкой отмены (`Cancel`). При удалении услуги, которая в данный момент редактируется, форма автоматически очищается.
3. **Валидация данных:** Перед сохранением выполняется проверка полей: название услуги должно содержать не менее 2 символов, а цена должна быть числом больше 0. Ошибки отображаются непосредственно под соответствующими полями и сбрасываются при вводе.
4. **Мемоизированная фильтрация (`reselect`):** Поиск по названию услуги выполняется в реальном времени без учета регистра через мемоизированные селекторы `selectFilteredServices` и `selectFilterStats` без дублирования данных в `state`.
5. **UX-оптимизация поиска:** Кнопка очистки (`✕`) сбрасывает поисковый запрос и автоматически возвращает фокус в поле ввода с помощью `useRef`. Реализовано отображение статистики (`Найдено: X из Y услуг`) и состояния пустого результата (`Услуги не найдены`).

## 🛠️ Технологический стек

* **Фронтенд:** React 19 (Функциональные компоненты, Хуки `useRef`)
* **Управление состоянием:** Redux, React-Redux (`useSelector`, `useDispatch`), Reselect (`createSelector`)
* **Утилиты:** NanoID (генерация уникальных идентификаторов)
* **Язык:** TypeScript 5 (Строгая типизация состояния, экшенов и редюсеров)
* **Сборщик:** Vite
* **CI/CD:** GitHub Actions (автоматическая сборка и деплой на ветку `gh-pages`)

## 🔧 Инструкция по установке и запуску

1. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone https://github.com/ivantr033/ra16-homeworks-editing-filter
   cd ra16-homeworks-redux
   ```

2. Установите зависимости:

   ```bash
   npm install --legacy-peer-deps
   ```

3. Запустите проект в режиме разработки:

   ```bash
   npm run dev
   ```

   Приложение откроется локально по адресу `http://localhost:5173`.

4. Для создания production-сборки выполните:

   ```bash
   npm run build
   ```
